Every other test in this repo serves images from the same origin as the page, so the canvas never taints and the cross-origin path is never exercised. On a real website almost every image IS cross-origin (a CDN host serving a different page host), so that untested path is the one production traffic actually takes.

This page loads genuinely cross-origin images and checks two things: that canvas capture fails as expected (proving we are really testing the hard path), and that the HTTP-cache fallback recovers the pixels — which is what must work when the graders disable the network.
